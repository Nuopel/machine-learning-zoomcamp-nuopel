## Execution Steps

### Phase 1: Create Dockerfile (15 minutes)

```dockerfile
# File: Dockerfile

FROM python:3.11-slim

WORKDIR /app

# Copy project files
COPY . .

# Install dependencies
RUN pip install --no-cache-dir -r requirements.txt

# Expose port
EXPOSE 9696

# Health check
HEALTHCHECK --interval=30s --timeout=10s --start-period=5s --retries=3 \
  CMD python -c "import requests; requests.get('http://localhost:9696/health')"

# Run app
CMD ["python", "-m", "src.serve"]
```

### Phase 3: Create README.md (45 minutes)

```markdown
# Wine Price Prediction

Predict French red wine prices using machine learning.

## Problem Statement

Wine consumers often struggle to identify fairly-priced wines. This project uses machine learning to predict wine prices from Vivino based on key characteristics (rating, vintage, region, grape variety, food pairings).

**Objective:** Build a regression model and deploy as a REST API.

## Dataset

**Source:** French red wines from Vivino (~72k wines)
**Target:** Price in EUR
**Features:**
- `vintage_year` (int) — Production year
- `rating` (float) — Vivino rating (0-5 scale)
- `region` (str) — Wine region (e.g., Bordeaux)
- `grape_variety` (str) — Main grape variety
- `food_pairings_count` (int) — Number of food pairings

## EDA Summary

- Price distribution: Right-skewed, range €5–€500
- Rating: Most wines rated 3.5-4.5
- Region: Bordeaux and Burgundy most common
- Strong correlation: rating ↔ price (r=0.65)

## Model Performance

| Model | Test RMSE | Test MAE | Test R² |
|-------|-----------|----------|---------|
| Linear Regression | €12.50 | €8.20 | 0.52 |
| Random Forest | €8.30 | €5.10 | 0.71 |
| **XGBoost** | **€6.80** | **€4.20** | **0.75** |

**Selected Model:** XGBoost (best test RMSE)

## API Usage

### /predict (POST)

Predict wine price from features.

**Request:**
```json
{
  "vintage_year": 2018,
  "rating": 4.2,
  "region": "Bordeaux",
  "grape_variety": "Cabernet Sauvignon",
  "food_pairings_count": 5
}
```

**Response (200 OK):**
```json
{
  "predicted_price_eur": 24.50,
  "model": "XGBoost",
  "input": { ... }
}
```

**Error (400 Bad Request):**
```json
{
  "error": "Rating must be 0-5, got 6"
}
```

### /health (GET)

Health check endpoint.

**Response (200 OK):**
```json
{
  "status": "healthy",
  "model_loaded": true
}
```

# File: tests/test_predict.py
"""Tests for prediction logic."""

import pytest
import pandas as pd
import numpy as np
from src.predict import PricePredictor


@pytest.fixture
def predictor():
    """Load predictor for tests."""
    return PricePredictor()


def test_predict_valid_input(predictor):
    """Test prediction with valid input."""
    result = predictor.predict({
        'vintage_year': 2018,
        'rating': 4.2,
        'region': 'Bordeaux',
        'grape_variety': 'Cabernet Sauvignon',
        'food_pairings_count': 5
    })
    assert 'predicted_price_eur' in result
    assert isinstance(result['predicted_price_eur'], float)
    assert result['predicted_price_eur'] > 0


def test_predict_invalid_rating(predictor):
    """Test prediction rejects invalid rating."""
    with pytest.raises(ValueError):
        predictor.predict({
            'vintage_year': 2018,
            'rating': 6.0,  # Out of range
            'region': 'Bordeaux',
            'grape_variety': 'Cabernet Sauvignon',
            'food_pairings_count': 5
        })


def test_predict_missing_field(predictor):
    """Test prediction rejects missing field."""
    with pytest.raises(ValueError):
        predictor.predict({
            'vintage_year': 2018,
            'rating': 4.2
            # Missing other fields
        })


# File: tests/test_serve.py
"""Tests for Flask API."""

import pytest
import json
from src.serve import app


@pytest.fixture
def client():
    """Create test client."""
    app.config['TESTING'] = True
    with app.test_client() as client:
        yield client


def test_health_endpoint(client):
    """Test /health endpoint."""
    response = client.get('/health')
    assert response.status_code == 200
    data = json.loads(response.data)
    assert 'status' in data
    assert data['status'] == 'healthy'


def test_predict_valid(client):
    """Test /predict with valid input."""
    response = client.post('/predict',
        data=json.dumps({
            'vintage_year': 2018,
            'rating': 4.2,
            'region': 'Bordeaux',
            'grape_variety': 'Cabernet Sauvignon',
            'food_pairings_count': 5
        }),
        content_type='application/json'
    )
    assert response.status_code == 200
    data = json.loads(response.data)
    assert 'predicted_price_eur' in data


def test_predict_invalid(client):
    """Test /predict with invalid input."""
    response = client.post('/predict',
        data=json.dumps({'rating': 6.0}),
        content_type='application/json'
    )
    assert response.status_code == 400
